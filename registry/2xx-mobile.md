# Реєстр спек додатку (2xx)

Власник файлу: мобільний розробник. Репозиторій спек: `moye-misto-mobile`, папка `specs/`.

Стан спеки тут не ведеться: його видно з pull request у репозиторії додатку. Цей файл змінюється лише тоді, коли додається нова спека.

Кожна спека додатку залежить від версії контракту та прикладів відповідей, а не від готовності парної спеки сервера.
