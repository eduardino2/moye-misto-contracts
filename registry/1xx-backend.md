# Реєстр спек сервера (1xx)

Власник файлу: серверний розробник. Репозиторій спек: `moye-misto-backend`, папка `specs/`.

Стан спеки тут не ведеться: його видно з pull request у репозиторії сервера. Цей файл змінюється лише тоді, коли додається нова спека.
