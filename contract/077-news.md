# 077 — Новини (news)

Діє з версії контракту `0.4.0`. Власник: серверний розробник.
Парні спеки: `177-news` (сервер), `277-news` (додаток).
Схема: `schemas/077-news.schema.json`. Приклади: `fixtures/077-news/`.

## Призначення

Стрічка новин лише з офіційних джерел: міська рада, обласна військова адміністрація, комунальні служби. Додаток показує заголовок, джерело й час і відкриває оригінал у вбудованому браузері (вирішено); повний текст у додаток не копіюється.

## Функція `list_news`

| Параметр | Тип | Обов'язковий | Опис |
|---|---|---|---|
| `p_city_id` | UUID | так | Місто |
| `p_source_slug` | код | ні | Лише одне джерело |
| `p_limit`, `p_cursor` | | ні | Див. `001-conventions`, розділ 6 |

**Відповідь** (`$defs/list_news`): `items[]`, `next_cursor`, `sources[]` — джерела для чипів фільтра (`slug`, `title`, `icon`).

**Картка новини** (`$defs/news_card`)

| Поле | Опис |
|---|---|
| `id` | Ідентифікатор |
| `title` | Заголовок |
| `summary` | Перше речення чи опис із джерела, до 300 символів, або `null` |
| `image` | Зображення або `null` |
| `source` | `slug` і `title` джерела |
| `published_at` | Момент публікації в джерелі |
| `is_important` | Позначку ставить адмін для оголошень, які мають бути вгорі (перекриття руху, графік води) |
| `url` | Адреса оригіналу |

Порядок: важливі за останню добу — першими, далі за часом публікації.

## Віджет головної `news`

Новий тип віджета в `get_home`: `config.title`, `config.limit` (1–5), `data` — відповідь `list_news` або `null`. Старі версії додатку його пропускають.

## Правила для сервера

1. Джерела — лише з переліку, який веде адмін; користувацьких новин немає.
2. Сервер не віддає матеріалів про наслідки влучань і роботу протиповітряної оборони: такі матеріали адмін прибирає, а автоматичний фільтр за ключовими словами відкладає їх на перевірку.
3. Новина, яку джерело видалило, зникає після наступної звірки.
4. `summary` береться з джерела без переписування.

## Правила для додатку

1. Дотик до картки відкриває `url` у вбудованому браузері додатку.
2. На кожній картці видно джерело й час публікації за часом міста.
3. Чипи джерел будуються з `sources`; невідома іконка замінюється стандартною.
4. Позначка «Важливо» показується для `is_important`.
5. Віджет `news` з `data = null` сам викликає `list_news` з `p_limit` із налаштувань; з порожнім списком не показується.

## Оновлення

Під час відкриття розділу, не частіше ніж раз на 10 хвилин; оновлення жестом.

## На що звернути увагу

- **Спосіб отримання новин** (RSS чи розбір сторінок) — питання спеки `177-news`.
- **Сповіщення про важливі новини** цим контрактом не передбачені.
