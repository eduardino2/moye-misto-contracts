# 031 — Офлайн-список і офлайн-карта (offline)

Діє з версії контракту `0.1.0`. Власник: серверний розробник.
Парні спеки: `131-offline-packs` (сервер), `231-offline` (додаток).
Схема: `schemas/031-offline.schema.json`. Приклади: `fixtures/031-offline/`.

## Призначення

Під час блекауту мобільний інтернет слабкий або відсутній. Тому на пристрої зберігаються дві речі:

| Що | Коли завантажується | Розмір | Для чого |
|---|---|---|---|
| **Офлайн-список** укриттів і пунктів незламності | автоматично, без участі користувача | сотні кілобайт | Найближче укриття списком із відстанню, маркери на карті, банер під час тривоги |
| **Офлайн-карта** міста | лише кнопкою користувача | десятки мегабайт | Підкладка карти без інтернету |

Маркери укриттів на офлайн-карті беруться з офлайн-списку, тому пакет карти містить лише саму карту.

## Функція `get_offline_manifest`

Каже, які файли актуальні. Самі файли додаток завантажує за посиланнями.

| Параметр | Тип | Обов'язковий | Опис |
|---|---|---|---|
| `p_city_id` | UUID | так | Місто |

**Відповідь** (`$defs/get_offline_manifest`)

| Поле | Опис |
|---|---|
| `safety_snapshot` | Опис файлу офлайн-списку; є завжди |
| `map_pack` | Опис файлу офлайн-карти; `null`, якщо пакет для міста ще не зібрано |

**Опис файлу** (спільні поля)

| Поле | Опис |
|---|---|
| `version` | Номер версії файлу; зростає з кожним новим файлом |
| `url` | Звідки завантажити |
| `size_bytes` | Розмір у байтах; показується перед завантаженням карти |
| `sha256` | Контрольна сума файлу, малими літерами |
| `updated_at` | Коли файл зібрано; показується як «Оновлено 1 листопада» |

Додаткові поля `safety_snapshot`: `items_count` — кількість об'єктів.

Додаткові поля `map_pack`: `format`, `min_zoom`, `max_zoom`, `bounds`.

**Помилки:** `city_not_found`.

## Файл офлайн-списку

Файл JSON (`$defs/safety_snapshot`): `city_id`, `version`, `generated_at`, `items[]`.

**Об'єкт списку**

| Поле | Опис |
|---|---|
| `id` | Ідентифікатор місця; той самий, що в `get_place` |
| `category` | `shelters` або `invincibility_points` |
| `title`, `address`, `location` | Назва, адреса, координати |
| `kind_title` | Тип готовим підписом: «Сховище», «Найпростіше укриття», «Мобільний» |
| `always_open` | Цілодобово |
| `hours_text` | Графік готовим рядком: «Цілодобово», «Щодня 08:00–20:00», «Відчиняється під час тривоги» |
| `capacity` | Місткість, осіб |
| `accessible` | Доступність для маломобільних; `null` — невідомо |
| `badges[]` | Позначки: обігрів, зарядка, зв'язок |
| `note` | Примітка: як знайти вхід |
| `valid_until` | Для тимчасових об'єктів (мобільний пункт незламності): до якого моменту діє |
| `verified_at` | Дата останньої перевірки |

Графік подано готовим рядком, а не структурою: офлайн-список має читатись без розрахунків і без звернення до сервера.

## Файл офлайн-карти

Формат `zip_pmtiles`: архів ZIP зі сталою структурою.

| Шлях в архіві | Вміст |
|---|---|
| `style.json` | Стиль карти з відносними посиланнями на файли архіву |
| `tiles.pmtiles` | Тайли міста в межах `bounds`, масштаби від `min_zoom` до `max_zoom` |
| `glyphs/` | Шрифти для підписів |
| `sprites/` | Іконки стилю |

## Правила для сервера

1. Файл із певним номером версії ніколи не змінюється: нові дані означають новий файл і нову адресу. Тому файли можна вільно кешувати.
2. Офлайн-список перезбирається, коли змінюється будь-яке укриття чи пункт незламності, але не частіше ніж раз на годину. Його `version` збігається з більшою з версій шарів `shelters` та `invincibility_points` або зростає разом із ними; точне правило описує спека `131-offline-packs`.
3. Об'єкти, у яких `valid_until` уже минув, у новий файл не потрапляють.
4. Попередні версії файлів лишаються доступними щонайменше 7 днів: хтось може саме завантажувати старий файл.
5. Файли віддаються зі стисненням під час передавання і з підтримкою докачування частинами.

## Правила для додатку

### Офлайн-список

1. Під час першого запуску з мережею і далі не рідше ніж раз на добу додаток викликає `get_offline_manifest`. Якщо `safety_snapshot.version` більша за збережену, він завантажує файл у фоні, **без запитань і без кнопок**.
2. Завантаження дозволене через мобільну мережу: файл малий.
3. Після завантаження перевіряється `sha256`. Якщо сума не збігається, файл відкидається, а старий лишається чинним.
4. Список зберігається в локальній базі. Найближчі об'єкти й відстань рахуються на пристрої.
5. Об'єкт із `valid_until` у минулому не показується, навіть якщо він є у збереженому файлі.
6. На екрані списку видно дату оновлення: «Список оновлено 8 листопада».
7. Якщо списку ще немає (перший запуск без мережі), екран чесно каже про це й пропонує підключитись до мережі.

### Офлайн-карта

1. За замовчуванням карта не завантажується.
2. Кнопка «Завантажити офлайн-карту» показує розмір із `size_bytes` і питає підтвердження. Через мобільну мережу додаток додатково попереджає про обсяг даних.
3. Під час першого відкриття шару укриттів додаток один раз пропонує завантажити карту.
4. Завантаження можна призупинити й продовжити; після завершення перевіряється `sha256`.
5. У налаштуваннях видно версію, дату й розмір карти; її можна оновити або видалити. Якщо `map_pack.version` більша за збережену, поруч є позначка «Є оновлення»; саме оновлення запускає лише користувач.
6. Якщо `map_pack` дорівнює `null`, кнопки завантаження немає.
7. Без мережі й без завантаженої карти вкладка «Карта» показує маркери на порожньому тлі та список найближчих укриттів.

`get_offline_manifest` — під час запуску додатку й не частіше ніж раз на 6 годин.

## Приклади

- `get_offline_manifest.default.json` — є і список, і карта.
- `get_offline_manifest.no_map_pack.json` — карту для міста ще не зібрано.
- `safety_snapshot.default.json` — вміст файлу списку (у прикладі п'ять об'єктів; у справжньому файлі понад тисячу).

## На що звернути увагу

- **Формат офлайн-карти не перевірено на практиці.** Чи відкриває MapLibre у Flutter локальний файл PMTiles зі шрифтами й іконками з диска, треба підтвердити коротким дослідом на початку спеки `231-offline`, до того як спека `131-offline-packs` почне збирати пакет. Якщо дослід покаже інше, формат змінюється запитом на зміну контракту; поле `format` для цього й існує. До запуску це не вважається зламом сумісності.
- **Офлайн-карта застаріває.** Вулиці змінюються рідко, а список укриттів часто. Тому їх розділено: список оновлюється сам, карта — за бажанням.
- **Достовірність.** Збережений список може бути старішим за стан на сервері. Дата оновлення на екрані обов'язкова.
- **Розмір пакета** в прикладі (45 МБ) умовний; справжній залежить від найбільшого масштабу. Що більший масштаб, то більший файл.
