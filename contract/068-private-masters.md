# 068 — Приватні майстри (private masters)

Діє з версії контракту `0.3.0`. Власник: серверний розробник.
Парні спеки: `168-private-masters` (сервер), `268-private-masters` (додаток).
Схема: `schemas/068-private-masters.schema.json`. Приклади: `fixtures/068-private-masters/`.

## Призначення

Приватні майстри (манікюр, брови, вії тощо) з фази 3 реєструються самі в кабінеті партнера й публікуються після перевірки. Для додатку майстер лишається місцем розділу «Сервіси» (`022-places`), але його сторінка отримує три доповнення: перелік послуг із цінами, ознаку перевірки й окрему причину скарги.

Прихована адреса працює так само, як у MVP: `address: null`, район і зміщена точка з `location_approximate: true`.

## Блок `master` у `get_place`

З версії `0.3.0` відповідь `get_place` має поле `master`: об'єкт для місць категорії приватних майстрів і `null` для решти. При встановленні тегу поле додається у схему `022`; до того його форму задає `$defs/master`.

| Поле | Опис |
|---|---|
| `verified` | Чи пройшов майстер перевірку модератора |
| `verified_at` | Дата останньої перевірки або `null` |
| `works_at_home` | Приймає в себе вдома |
| `home_visit` | Виїжджає до клієнта |
| `services[]` | Послуги: `title`, `price_from` (цілі гривні або `null`), `duration_min` (хвилини або `null`); до 30 |
| `profile_updated_at` | Коли майстер востаннє оновлював профіль |

Роботи майстра — це наявний масив `images` сторінки місця.

## Скарга на профіль

До причин `submit_report` (`060-reports`) для місць категорії приватних майстрів додається `fake_profile` («Профіль несправжній або неактивний»). Сервер приймає її лише для таких місць.

## Правила для сервера

1. Неперевірений профіль не публікується зовсім: у відповідях його немає.
2. Профіль, який майстер не оновлював понад 90 днів, сервер ховає автоматично й повідомляє майстра в кабінеті.
3. У `services` немає медичних процедур, що потребують ліцензії; це перевіряє модерація.
4. Точна адреса майстра, який її приховав, не повертається жодною функцією.

## Правила для додатку

1. Блок послуг показується на сторінці місця, якщо `master` не `null` і `services` не порожній. Ціна — «від N грн»; без ціни — лише назва.
2. Ознака `verified` показується позначкою «Перевірений майстер» із датою.
3. Якщо `works_at_home` і адресу приховано, сторінка каже «Точну адресу повідомлять під час запису»; кнопки «Маршрут» немає (правило MVP).
4. Запису через додаток немає: лише «Подзвонити» й «Написати».
5. Причина `fake_profile` показується у формі «Повідомити про проблему» першою для таких місць.

## Приклади

- `master.default.json` — майстриня з чотирма послугами.
- `master.minimal.json` — без цін і тривалості.

## На що звернути увагу

- **Якість перевірки** визначає довіру до розділу: підтверджений телефон і сторінка з роботами — мінімум (`168-private-masters`).
- **Лояльність.** Майстер може брати участь у програмі нарівні із закладами й сканувати QR зі свого телефона (`085-qr`).
