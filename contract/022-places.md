# 022 — Місця і сервіси (places)

Діє з версії контракту `0.1.0`. Власник: серверний розробник.
Парні спеки: `122-places` (сервер), `222-places` і `223-services` (додаток).
Схема: `schemas/022-places.schema.json`. Приклади: `fixtures/022-places/`.

## Призначення

Місце працює постійно й дати завершення не має: музей, парк, ресторан, укриття, автомийка, перукарня. Для сервера сервіси, заклади харчування, укриття та АЗС — це ті самі місця в різних категоріях, тому контракт один.

## Картка місця

Спільна форма для списків і сторінки (`$defs/place_card`).

| Поле | Опис |
|---|---|
| `id`, `title`, `image` | Ідентифікатор, назва, обкладинка (може бути `null`) |
| `categories[]` | Коди категорій; перша — основна |
| `address` | Адреса; `null`, якщо точну адресу приховано |
| `district` | Район міста; для прихованої адреси це єдине, що показується |
| `location` | Координати; `null`, якщо їх немає |
| `location_approximate` | `true` — точка приблизна (приватний майстер без точної адреси) |
| `open_status` | Чи відкрито зараз, див. нижче |
| `price_text` | Готовий підпис ціни: «Середній чек 180 грн», «від 300 грн», «Вхід від 60 грн»; або `null` |
| `contacts[]` | Способи зв'язку для кнопок «Подзвонити» й «Написати» |
| `badges[]` | Позначки з готовими підписами: «Працює без світла», «Цілодобово» |
| `is_promoted` | Платне просування; у MVP завжди `false` |
| `distance_m` | Відстань від точки `p_near` або `null` |
| `verified_at` | Дата останньої перевірки даних; обов'язково показується на укриттях і пунктах незламності |

### «Відкрито зараз»

`open_status.state`:

| Значення | Підпис |
|---|---|
| `open` | «Відкрито до 21:00» |
| `closed` | «Зачинено · відкриється о 08:00» |
| `always_open` | «Цілодобово» |
| `unknown` | підпису немає: графік невідомий |

`changes_at` — момент наступної зміни стану. Сервер рахує стан на момент відповіді; коли `changes_at` минає, додаток сам перемикає `open` на `closed` і навпаки, не чекаючи нового запиту. Після такого перемикання час наступної зміни невідомий, тому підпис скорочується до «Відкрито» чи «Зачинено» до наступного оновлення.

### Контакти

Кожен контакт має `type`, підпис `title` і готове посилання `url`, яке додаток просто відкриває.

| `type` | Вид `url` |
|---|---|
| `phone` | `tel:+380…` |
| `email` | `mailto:…` |
| `viber` | `viber://…` |
| `telegram`, `whatsapp`, `instagram`, `facebook`, `website` | `https://…` |

Кнопка «Подзвонити» бере перший контакт типу `phone`; «Написати» відкриває вибір з решти контактів.

## Функція `list_places`

**Параметри**

| Параметр | Тип | Обов'язковий | Опис |
|---|---|---|---|
| `p_city_id` | UUID | так | Місто |
| `p_category_slug` | код | один із двох | Категорія |
| `p_section_slug` | код | один із двох | Увесь розділ, наприклад `services` |
| `p_filters` | об'єкт | ні | Значення власних фільтрів категорії (`020-catalog`) |
| `p_query` | рядок | ні | Пошук за назвою й адресою; від 2 символів |
| `p_open_now` | логічне | ні | Лише місця, що відкриті зараз або працюють цілодобово |
| `p_near` | об'єкт | ні | `{ "lat": …, "lng": …, "radius_m": … }`; `radius_m` необов'язковий |
| `p_sort` | `distance`, `popular`, `title` | ні | За замовчуванням `default_sort` категорії |
| `p_limit`, `p_cursor` | | ні | Див. `001-conventions`, розділ 6 |

**Відповідь** (`$defs/list_places`): `items[]` — картки, `next_cursor`.

**Помилки:** `city_not_found`; `invalid_argument` — не передано ні категорії, ні розділу, або `p_sort: "distance"` без `p_near`; `not_found` — невідома категорія чи розділ.

## Функція `list_place_points`

Точки для режиму «На карті». Приймає ті самі параметри, що й `list_places`, крім `p_sort`, `p_limit` і `p_cursor`.

**Відповідь** (`$defs/list_place_points`): `points[]` — точки карти (`map_point` з `kind: "place"`), `truncated` — `true`, якщо місць більше за 500.

Для місця з `location_approximate` точка має `approximate: true`; додаток малює її колом, а не шпилькою.

Шар карти без фільтрів додаток бере не звідси, а з `get_map_layer` (`030-map`): той запит кешується за версією.

## Функція `get_place`

| Параметр | Тип | Обов'язковий | Опис |
|---|---|---|---|
| `p_place_id` | UUID | так | Місце |

**Відповідь** (`$defs/get_place`)

| Поле | Опис |
|---|---|
| `card` | Та сама картка, що й у списку |
| `description` | Опис |
| `images[]` | Фото для галереї |
| `opening_hours` | Графік роботи або `null`, якщо невідомий |
| `attributes[]` | Характеристики з готовими підписами: тип закладу, місткість укриття, види пального |
| `upcoming_events[]` | Блок «Події тут»: до 5 найближчих подій у цьому місці (картки з `021-events`) |
| `fuel_prices[]` | Ціни на пальне для АЗС; порожній масив, якщо цін немає |
| `source` | Звідки дані |
| `share_url` | Посилання для кнопки «Поділитись» |
| `updated_at` | Коли місце востаннє змінювали |

**Графік роботи** (`opening_hours`)

| Поле | Опис |
|---|---|
| `always_open` | `true` — цілодобово; тоді `weekly` порожній |
| `weekly[]` | Дні тижня: `day` від 1 (понеділок) до 7 (неділя) і проміжки `from`–`to`. День без проміжків — вихідний. Дня немає в масиві — графік на цей день невідомий |
| `exceptions[]` | Особливі дати: `closed` або власні проміжки, з поясненням `note` |
| `note` | Примітка до графіка |

Проміжок, що закінчується після півночі, записується з `to` меншим за `from` (наприклад `22:00`–`04:00`).

**Ціна пального** (`fuel_prices[]`): `fuel` (код), `title`, `price` у гривнях за літр, `updated_at`. Ціна завжди показується разом із часом оновлення.

**Помилки:** `not_found`.

## Правила для сервера

1. **Прихована адреса.** Якщо місце має ознаку «не показувати точну адресу», сервер віддає `address: null`, заповнений `district`, `location_approximate: true` і координати, зміщені так, щоб справжню адресу не можна було відновити. Точних координат у відповіді немає взагалі; зміщення стале для місця, а не нове при кожному запиті.
2. Пошук «поруч» і сортування за відстанню для таких місць рахуються від зміщеної точки.
3. `open_status` рахується з `opening_hours` з урахуванням винятків і часового поясу міста.
4. Мобільний пункт незламності з терміном дії зникає зі списків після його завершення.
5. Усі URL у відповіді, крім `tel:`, `mailto:` і `viber://`, починаються з `https://`.

## Правила для додатку

1. Сторінка місця, відкрита зі списку чи карти, одразу показує вже отримані дані й довантажує решту.
2. Кнопка «Маршрут» відкриває зовнішній застосунок карт із координатами місця. Для місця з приблизною точкою кнопки немає.
3. Контакт невідомого `type` показується загальною іконкою посилання, якщо `url` починається з `https://`; інакше пропускається.
4. На картці укриття й пункту незламності показується `verified_at` («Перевірено 28 жовтня») і кнопка «Повідомити про проблему» (`060-reports`).
5. Картка сервісу має три кнопки: «Подзвонити», «Написати», «Маршрут»; кнопка без відповідних даних ховається.

## Оновлення

Список — під час відкриття категорії, зміни фільтрів і коли користувач тягне екран донизу. Сторінка місця — під час кожного відкриття.

## Приклади

- `list_places.food.json` — «Поїсти» з відстанню.
- `list_places.services.json` — розділ «Сервіси»: цілодобова автомийка, барбершоп, приватний майстер із прихованою адресою; є наступна сторінка.
- `list_places.empty.json` — нічого не знайдено.
- `list_place_points.default.json` — точки для карти.
- `get_place.restaurant.json` — заклад із графіком і винятком.
- `get_place.museum.json` — музей із блоком «Події тут» і вихідним понеділком.
- `get_place.shelter.json` — цілодобове укриття з датою перевірки.
- `get_place.gas_station.json` — АЗС із цінами на пальне.
- `get_place.private_master.json` — приватний майстер із прихованою адресою: `address: null`, район, зміщена точка з `location_approximate: true`.

Назви закладів, телефони й адреси в прикладах вигадані.

## На що звернути увагу

- **Приватні майстри** з'являться лише у фазі 3, але приховану адресу закладено в контракт уже зараз: додавати її пізніше означало б міняти форму картки. Картка майстра в прикладі `list_places.services.json` показує, як це виглядатиме; у MVP таких записів немає.
- **Ціни на пальне.** Поле є, але в MVP масив порожній: джерела цін немає. Приклад `get_place.gas_station.json` показує майбутній вигляд.
- **`price_text` — готовий рядок.** Для місць «ціна» означає різне (середній чек, ціна стрижки, вхідний квиток), тому сервер віддає підпис, а не число. Фільтр за ціною при цьому працює: він описаний у каталозі й рахується на сервері.
- **Оцінки й рейтинг** (фаза 6) додадуться новими полями картки; це зміна MINOR.
- **Достовірність укриттів.** Контракт не може гарантувати, що укриття відчинене. Він лише передає дату перевірки й дає надіслати повідомлення про проблему.
