# moye-misto-contracts

Спільний репозиторій проєкту «Моє Місто»: контракт між сервером і мобільним додатком, схеми й приклади відповідей, реєстри спек і правила асинхронної роботи.

Продуктовий план лежить у `PLAN.md` у корені проєкту. Як працювати зі спеками, описано у [WORKFLOW.md](WORKFLOW.md).

## Структура

| Шлях | Зміст | Власник |
|---|---|---|
| `WORKFLOW.md` | Правила: нумерація, власники файлів, запити на зміну, рев'ю | Серверний розробник |
| `contract/0xx-*.md` | Контракт: функції, параметри, відповіді, правила для сервера й додатку | Серверний розробник |
| `schemas/*.schema.json` | Формальні схеми JSON до кожної відповіді | Серверний розробник |
| `fixtures/0xx-*/` | Приклади відповідей у JSON | Серверний розробник |
| `tools/check-fixtures.mjs` | Перевірка, що приклади відповідають схемам | Серверний розробник |
| `CHANGELOG.md` | Історія версій контракту | Серверний розробник |
| `registry/1xx-backend.md` | Перелік спек сервера | Серверний розробник |
| `registry/2xx-mobile.md` | Перелік спек додатку | Мобільний розробник |
| `requests/` | Запити мобільного розробника на зміну контракту та відповіді на них | Запит — мобільний; відповідь — серверний |

## Як пов'язані опис, схема і приклад

- Опис у `contract/` пояснює зміст і правила поведінки.
- Схема в `schemas/` точно задає форму відповіді. Якщо опис і схема розходяться, це помилка контракту: її виправляє серверний розробник.
- Приклад у `fixtures/` — конкретна відповідь для одного сценарію.

Відповідність за назвою: приклад `fixtures/<контракт>/<назва>.<сценарій>.json` перевіряється схемою `schemas/<контракт>.schema.json`, визначення `$defs/<назва>`. Наприклад, `fixtures/010-alerts/get_alert_state.red.json` відповідає `schemas/010-alerts.schema.json#/$defs/get_alert_state`.

## Перевірка

Потрібен Node.js 18 або новіший; залежностей немає.

```bash
node tools/check-fixtures.mjs
```

Перевірка має проходити перед кожним злиттям у цьому репозиторії. Вона розуміє лише ту частину JSON Schema, якою користується контракт; на невідоме ключове слово у схемі вона зупиняється з помилкою.

Сервер у власних тестах перевіряє справжні відповіді тими самими схемами будь-якою бібліотекою JSON Schema (чернетка 2020-12). Додаток будує тестові джерела даних із прикладів.
